# CrestMotive Group website prototype

A dependency-free static website designed for direct deployment to Vercel.

## Working assumptions
- `CrestMotive Group` is a temporary working brand pending domain and trademark clearance.
- The legal contracting entity is intentionally not stated until the Cyprus/Paraguay structure is finalised.
- The contact form is intentionally non-transmitting until a CRM/form endpoint and privacy process are configured.
- Regulated Australian tax, legal and insolvency services are explicitly excluded from the consultancy scope unless delivered by qualified independent professionals.

## Deploy to Vercel
1. Create a GitHub repository and upload/push these files.
2. In Vercel, create a new project and import the GitHub repository.
3. Vercel can serve this project as static files; there is no package install or build step.
4. Add the final domain in Vercel and point DNS through Cloudflare.
5. Replace every `REPLACE-DOMAIN.com` occurrence before launch.

## Before public launch
- Finalise brand name and trademark/domain clearance.
- Replace legal entity wording in footer/About/Privacy.
- Configure the contact form to the selected CRM or secure server endpoint.
- Add analytics only after privacy/cookie requirements are reviewed.
- Replace placeholder privacy page with a final policy.
- Review all service claims and Australian regulated-advice boundaries with legal/tax advisers.
